## 项目简介与通用价值

回答“接口升级是否破坏调用方”和“实际响应是否符合约定”，产出可在 CI 使用的测试报告。项目采用 MoonBit 实现核心处理能力，提供可复用库接口与命令行入口，使使用者能够把同一能力嵌入应用、离线处理或 CI 流程。适用范围通过不同用途的完整示例说明，并以输入、判断过程和可核验输出体现实际价值。

## 核心功能

OpenAPI 3.0 JSON 适配；引用图解析；参数与 schema 模型；兼容性差异分类；样例和边界请求生成；请求/响应校验；本地 HTTP 执行适配；结果报告。复用 HTTP/schema 库时记录版本和来源，核心契约与兼容性语义自行实现。

## 三个完整使用场景

1. 内部 API 升级审查：输入订单接口的新旧 OpenAPI 文件，比较字段、参数、枚举和状态码；输出兼容与破坏变更及其契约路径，让维护者决定是否需要版本迁移。

2. 前后端联调：输入分页接口契约和边界请求，调用本地测试服务并校验实际响应；输出必填字段、类型、状态码和错误响应不符项，作为 CI 中可复现的联调检查。

3. 第三方服务接入：输入脱敏响应录制和适配层契约，通过本地桩重放正常、缺字段和错误类型响应；输出契约违反报告，供接入开发者确定容错和拒绝边界。

## 技术路线与工程实现

将 OpenAPI 文档解析为有来源路径的契约模型，以引用图管理 schema；差异分类器和运行校验器独立实现，网络执行通过可替换传输层接入。核心逻辑采用有类型的数据结构、明确错误结果和可测试执行步骤；文件、网络或进程适配与核心处理分层。实现过程中用小规模确定性输入建立正确性基准，再使用真实场景和规模数据检查可用性。对外暴露稳定接口，避免把演示脚本作为唯一使用方式。

## 预计交付与验收方式

交付目标包括公开 MoonBit 源码、库接口、CLI、三个完整场景及输入来源、单元与集成测试、适用目标的 CI、安装使用说明、设计与边界文档、源码统计及独立安装验证记录。有效生产 MoonBit 源码内部估算为 5,000–8,000 行，测试、示例、生成语料和辅助脚本分别统计，该估算不作为官方验收门槛。

预标注的兼容性语料分类一致；三场景捕获预先植入的破坏变更；对数百 operations 的规格记录处理耗时。失败验证覆盖引用循环、不存在引用、不支持关键字、响应类型错与参数缺失。未知语义明确拒绝或标记未检查，不能静默作为通过。十月不承诺完整 OpenAPI/YAML/所有 JSON Schema 草案。
